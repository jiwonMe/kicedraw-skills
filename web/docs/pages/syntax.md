## 한 파일의 순서

1. 헤더: `@version`, `@frame`, 필요할 때 `@axes`와 수치 선언.
2. 객체: 한 줄에 `ID: 생성자(인자)`. 먼저 선언한 점과 경로를 이름으로 참조합니다.
3. 제약(선택): `---constraints---` 아래에 생성자로 표현하지 못한 관계만 추가합니다.
4. 표시: `---annotations---` 아래에 이름, 점선, 직각, 텍스트, 음영 등을 선언합니다.

주석은 `#`로 시작합니다. ID는 영문자 또는 밑줄로 시작하고 이후에 숫자도 사용할 수 있습니다. 한 점에 여러 이름을 붙이기 위해 동일한 좌표의 점을 여러 번 선언하지 마세요.

## 좌표와 인쇄 폭

| 항목 | 의미 |
| --- | --- |
| `@frame: x=-5, y=-4, width=10, height=9` | 수학 좌표에서 왼쪽 아래 모서리와 양의 폭·높이. x는 오른쪽, y는 위쪽이 양수입니다. |
| `@axes` | 축의 표시 범위와 눈금. 축과의 교점이나 수선에는 `Axis(x)`, `Axis(y)`를 참조합니다. |
| `--width-mm 90` | CLI 출력의 실제 가로 폭. 프레임 좌표 단위를 mm로 바꾸는 옵션이 아닙니다. |

## 수치 표현과 풀이

| 선언 | 용도 | 쓰는 곳 |
| --- | --- | --- |
| `@let: a = 18/2` | 앞에서 선언한 수나 수식을 평가 | `${a}`처럼 치환 |
| `@solve: h = root(0, a; h^2-5)` | 지정 구간에서 연속 잔차의 실근을 찾음 | `${h}`처럼 치환 |
| `@const: a=2 [-5..5 step 0.5], b=-1` | 함수식에서 이름으로 참조하는 문서 상수 | `Function("a*x+b", xMin=-2, xMax=2)` |

`@let`과 `@solve`는 **로드 시 선언 순서대로** 평가되며, `@let` 한 줄에 이름 하나를 선언합니다. `root(하한, 상한; 잔차)`에는 의도한 근을 포함하고 잔차의 부호가 양끝에서 바뀌는 구간을 주는 것이 안전합니다. 여러 근이 있는 식이라면 구간을 좁혀 원하는 근만 선택하세요. 치환은 수치 인자, 배열 원소, 곡선 식 안에 사용할 수 있습니다. 스칼라 삼각함수는 라디안이고 `RotatePoint(..., angle=...)`는 도 단위입니다.

좌표계의 크기나 카메라 각은 구도를 위한 값입니다. 문제의 조건에서 나오는 길이나 각도는 가능하면 생성자로, 필요한 경우 스칼라 식으로 표현하세요. [수치 풀이 실습](/docs/learn/)에 실행 가능한 전체 파일이 있습니다.
