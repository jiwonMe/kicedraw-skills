## 명령과 입력

설치된 스킬 폴더(또는 저장소의 `skills/kicedraw/`)에서 실행합니다.

~~~sh
node bin/kicedraw.mjs --version
node bin/kicedraw.mjs check figure.dsl --width-mm 90
node bin/kicedraw.mjs svg figure.dsl figure.svg --width-mm 90
node bin/kicedraw.mjs png figure.svg figure.png
~~~

| 명령 | 결과와 종료 코드 |
| --- | --- |
| `check` | 문법·기하·조판을 검사합니다. 오류가 있으면 1, 경고만 있거나 문제가 없으면 0입니다. |
| `svg` | DSL을 검증하고 지정 폭의 수능 인쇄용 SVG를 만듭니다. |
| `png` | 이 CLI에서 만든 자체 포함 SVG를 300dpi 상당 PNG로 변환합니다. 성공 0, 오류 1, 로컬 렌더러 부재 등으로 보류 2입니다. |

자동화나 특정 버전 재현에서는 `KICEDRAW_NO_UPDATE=1`을 환경 변수로 지정하고 CLI 버전을 기록하세요. PNG 출력을 사용하려면 로컬 렌더러(resvg, Chromium 등)가 필요합니다. SVG 자체는 브라우저에서 바로 열 수 있습니다. PNG 보류는 시각 검수 통과가 아닙니다.

## 어떤 순서로 고치나요?

CLI 메시지의 `L12`는 원본 DSL의 12번째 줄입니다. `SNG-E`는 먼저 고쳐야 할 오류, `SNG-W`는 실제 도면과 대조해 판단할 경고입니다.

| 코드 | 의미와 대응 |
| --- | --- |
| `SNG-E01` | 문법·참조 오류. 줄 번호의 ID, 참조 순서, 괄호, 인용부호를 확인합니다. |
| `SNG-E02` | 정의되지 않는 기하. 교점이면 두 경로가 실제로 만나는지, 유한 선분·함수 정의역 안인지, 해당 `index`가 있는지 확인합니다. |
| `SNG-E03` | 채울 면이 없습니다. 경계가 닫히고 시드가 내부에 있는지 확인합니다. |
| `SNG-E04` · `SNG-E05` | LaTeX의 이중 역슬래시 · 점 라벨 정체 문제. `\mathrm{A}`처럼 역슬래시 한 개와 정체를 사용합니다. |
| `SNG-E06` | 점이나 텍스트가 출력 범위 밖입니다. `@frame`과 그래프 표시 범위를 구분해 점검합니다. |
| `SNG-W01` · `SNG-W02` | 라벨 여백이 부족하거나 점이 너무 가깝습니다. 점의 위치를 바꾸기 전에 인쇄 폭과 라벨 방향·거리를 확인합니다. |
| `SNG-W03` | 축 눈금이 많습니다. 불필요한 눈금을 줄이고 필요한 좌표만 표시합니다. |
| `SNG-W04` · `SNG-W05` | 의도치 않은 직각·등변 배치 또는 중점·교점에 가까운 독립점. 실제 조건이라면 관계로 선언하고, 단순 배치라면 오해가 없도록 조정합니다. |
| `SNG-W06` | 두 선분이 매우 작은 각을 이룹니다. 발문의 조건은 유지하고 실제 인쇄 폭에서 구분되는지 확인합니다. |

## 최종 확인

1. 주어진 조건, 독립점, 파생 관계가 발문과 일치하는지 확인합니다.
2. `check`와 `svg`에 같은 인쇄 폭을 줍니다. 경고는 줄 번호를 따라 보되, 이미 주어진 예각처럼 의미상 유지해야 하는 조건을 임의로 바꾸지 않습니다.
3. SVG 또는 PNG를 열고 점 이름, 직각 기호, 끝점, 보이는 선/숨은 선, 음영을 검토합니다.
4. DSL과 SVG를 함께 보관하고, PNG가 필요하면 같은 SVG에서 만듭니다.
