# 신규 작도

1. 발문에서 주어진 것, 구할 것, 도면이 단정하면 안 되는 것을 구분한다. 예컨대 “삼각형”만 주어지면 직각으로 고정하지 않는다. 출제 의도가 모호하면 서로 다른 구도 세 가지와 각각 드러내는 관계를 제시하고 선택을 받는다.
2. [구도 예제](visual-grammar.md)를 보고 독립점 → 경로 → 파생점 → 표식 순으로 [DSL](dsl-cheatsheet.md)을 작성한다. 외부점 접선의 실행 예시는 [tangent-area.dsl](../assets/examples/tangent-area.dsl)이다.
3. `node bin/kicedraw.mjs svg`로 실제 납품 폭에서 검증·출력한다. 오류는 원본 DSL에서 고친다. 파싱 성공이 교점 인덱스나 음영 선택의 정당성을 보장하지는 않는다.
4. `node bin/kicedraw.mjs png` 결과를 열고 실제 폭을 기준으로 라벨·끝점·직각 방향·음영 경계를 발문과 대조한다. 변경하면 SVG와 PNG를 모두 다시 만든다.
5. [납품 양식](../SKILL.md)에 따라 원본 DSL과 SVG, 생성 가능한 경우 PNG를 제공한다. 렌더러 부재는 검수 보류이지 시각 검수 통과가 아니다.
