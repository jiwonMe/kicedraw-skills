# 실제 인쇄 폭에서 판단하기

[standard.json](../assets/standard.json)의 `print`는 기존 ClassGeo 인쇄 프리셋이다. 평가원 도면의 대략적인 실측값을 반영한 스타일이며 공식 규격 인증이 아니다. 기본 폭 60mm, 주선 0.20mm, 열린/닫힌 점의 기본 반지름 0.45mm, 글자 9pt. 빗금 선은 0.10mm, 간격은 1.0mm다. 실제 폭은 SVG 루트의 `width`에서 확인한다. 60mm를 300dpi로 래스터화하면 폭은 709px이다.

`lint`는 **별도의 프로젝트 검토 기준**이다. 표시 점간 2.5mm, 라벨과 비부모 경로 사이 0.5mm, 공유 꼭짓점의 내각 12°가 기준이다. 꼭 필요한 협각은 관계를 바꾸지 말고 먼저 프레임·인쇄 폭을 조정한다. 해당 경고가 나타나면 `node bin/kicedraw.mjs check`가 보고한 객체와 실제 인쇄본을 함께 확인한다.

점 라벨 `label="$\mathrm{A}$"`와 수식 `text="$y=f(x)$"`를 구분한다. 점 이름을 기울이거나 `\\mathrm`처럼 JSON 이스케이프를 DSL에 그대로 옮기지 않는다. 한글 일반 텍스트는 시스템 폰트에 따라 달라지므로 실제 SVG/PNG로 확인한다. 80mm 도면이 필요하면 `--width-mm 80`으로 다시 내보낸다. 이미 만든 60mm SVG를 통째로 확대하면 선과 글자도 커진다.
