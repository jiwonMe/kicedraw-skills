# 기존 도면 비평

1. 비평만 요청하면 원본을 수정하지 않는다. 발문과 DSL·SVG의 버전이 같은지 먼저 확인하고 원본을 보존한 채 임시 경로에 내보낸다.
2. 수학적 오류를 먼저 찾는다. 점 이름보다 점의 생성자를 보고, 교점·접점이 `FreePoint`로 흉내 낸 것은 아닌지, 교점 인덱스와 정의역이 맞는지 검사한다. 시드는 경계선 위가 아닌 원하는 닫힌 면 안에 있어야 한다.
3. 실제 인쇄 폭에서 라벨 충돌, 숨은선과 보이는 선의 혼동, 이탤릭 꼭짓점, 의도치 않은 직각·등변, 답을 누설하는 눈금을 찾는다. PNG가 없으면 보이는 것으로 확인한 결함과 DSL에서만 추정한 위험을 구분한다.
4. 각 지적은 `객체 ID/줄 → 발문과 어긋난 점 → 영향 → 최소 수정안` 순으로 보고한다. 수정 요청을 받은 경우 파생 관계를 보존해 고치고 다시 검증·렌더한다.
